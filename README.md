# Minecraft Chest and Shulker Texture Pack

Rastreador Cromátic is a Minecraft texture pack with chest and shulker box textures featuring colored stripes. The textures are provided in green, yellow, and red variants to represent distance categories.

## Install

1. Choose the green, yellow, and red textures for chests and shulker boxes.
2. Convert the SVG files in `assets/textures/` to PNG files, since Minecraft resource packs use PNG textures.
3. Place the converted textures in the matching locations in a Minecraft resource pack for your game version, using the required texture filenames.
4. Zip the resource pack folder and put it in your Minecraft `resourcepacks` folder.
5. Open Minecraft, go to Options → Resource Packs, and enable the pack.

## Use

Use the colored textures to distinguish chest and shulker box variants: green for nearby, yellow for medium distance, and red for far away. The pack supplies static textures only; it does not detect container locations, draw markers in the world, change colors based on distance, or add server-side functionality. Select or configure the appropriate texture variant yourself.
